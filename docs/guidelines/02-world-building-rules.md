# World Building Rules

## Purpose

This document defines the non-negotiable rules that maintain consistency across the entire world.

Every new island, building, feature, interaction, or expansion must follow these rules.

---

# Rule 1

The world comes before the UI.

Bad:

Project card with island image.

Good:

Island containing project content.

---

# Rule 2

Every location must have purpose.

No decorative islands.

Every island must represent:

* Information
* Story
* Navigation
* Functionality

---

# Rule 3

The ship is always the central hub.

Visitors should always understand:

"I am exploring from the ship."

---

# Rule 4

Navigation must feel like travel.

Avoid:

Instant page switching.

Prefer:

Travel
Transition
Journey

---

# Rule 5

Content should be discovered.

Avoid traditional page layouts whenever possible.

---

# Rule 6

World scale must remain believable.

Do not continuously add islands without purpose.

Quality over quantity.

---

# Rule 7

Fantasy supports information.

Fantasy never hides information.

Portfolio content remains the priority.
